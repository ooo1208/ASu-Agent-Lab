# ASu Agent Lab

企业 Agent 运行时与评估实战：采购业务、MCP、多 Agent、隔离沙箱、持久记忆、文档证据、财务计算和异步评估。

本仓库按章节整理实现。章节依据公开课程目录线索和多个公开工程的共同结构推测还原，并补充工程缺口；**不是官方课程源码或官方章节复刻**。提交使用实际时间，不代表原项目的历史开发过程。

基础 Agent 代码来自 [KagaribiDev/procurepilot](https://github.com/KagaribiDev/procurepilot)，保留 MIT 许可。来源、差异和新增模块见 [SOURCES.md](SOURCES.md)。本地配置、模型密钥和运行数据不进入 Git。

## 学习顺序

参见 [章节路线](docs/CHAPTERS.md)。每章有对应提交与标签，前期按模块阅读，完整应用在整合章节运行。新增 Java ERP、文档证据与评估代码的功能和验证记录随相应章节加入。
